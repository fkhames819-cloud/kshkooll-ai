# FA5 AI — Lesson Builder

واجهة عربية لإنشاء صفحات دروس HTML مدمجة انطلاقًا من ملفات PDF.

## تشغيل المشروع
افتح `index.html` في متصفح حديث مع اتصال بالإنترنت لتحميل PDF.js وخط Cairo.

## الإصدار الحالي
- رفع ملف PDF من الجهاز أو سحبه إلى منطقة الرفع.
- استخراج النص من صفحات PDF داخل المتصفح باستخدام PDF.js.
- كتابة وصف الدرس المطلوب.
- إنشاء مسودة صفحة HTML مستقلة بتنسيق CSS مدمج داخلها.
- معاينة الناتج ونسخ الكود أو تنزيل ملف HTML.
- خيارات لإضافة ملخص وأسئلة مراجعة أولية.

## حدود النسخة التجريبية
هذا الإصدار لا يستخدم نموذج ذكاء اصطناعي بعد. يقوم باستخراج النص وعرضه في قالب منسق، ويضيف أسئلة مراجعة عامة. لذلك فهو لا يعيد صياغة محتوى الكتاب أو ينشئ شرحًا تربويًا ذكيًا من تلقاء نفسه. الملفات التي تعتمد على صور ممسوحة ضوئيًا قد تحتاج OCR، وهو غير مضاف حاليًا.

## الأمان والمرحلة التالية
عند إضافة نموذج AI، يجب أن يتم الاتصال من خلال Backend أو وظيفة Serverless لحماية مفتاح API. لا تضع مفاتيح سرية في ملفات الواجهة الأمامية.
